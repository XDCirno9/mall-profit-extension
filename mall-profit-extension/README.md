# 鸢尾花商城利润筛选器

这是一个适用于 Chrome / Edge 的 Manifest V3 扩展。打开 `https://mall.vesego.xyz/` 后，页面右下角会出现“利润排行”按钮，点击即可使用。

当前版本：`v1.7.0`

## 功能

- 读取商城公开报价接口，不抓取页面 DOM。
- **点击利润列表里的商品名称，会直接在商城页面中打开该物品的详情（物品报价 / 历史价格），不需要手动关闭面板再去搜索。**
- 单件利润 = `最高收购价 - 最低出售价`，只保留正利润商品。
- 支持最低在售数量筛选，只显示 sellAmount 不低于指定值的商品。
- 支持按 vanillaId 筛选“原版 + 非原版”“仅原版”或“仅非原版”。
- 支持港口黑名单：屏蔽指定港口后，重新计算价格、在售数量和总利润。
- 港口黑名单支持 JSON 文件导出和 JSON/TXT/CSV 导入，并保存在扩展中。
- 支持同商品异常报价过滤，可切换关闭、严格 5×、推荐 10× 和宽松 20×。
- 异常过滤按同商品报价中位数判断，低于中位数 1/N 或高于中位数 N 倍的报价会被剔除；小样本报价使用最大相邻价差判断。
- 支持按单件利润、总利润、利润率和最低出售价排序。
- 总利润会根据报价中的可交易数量，将最低出售报价与最高收购报价进行最优匹配。
- 忽略港口距离、传送和运输成本。
- 默认使用 `includeTagged=false`，遵从商城对标记商店和失效商店的处理。
- 商品列表、总利润和异常过滤结果都会缓存 5 分钟。
- 开始计算、重新计算均需手动点击，不会在打开面板或切换筛选条件时自动启动。
- 总利润计算显示进度，可随时停止。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`mall-profit-extension`。
5. 打开或刷新 `https://mall.vesego.xyz/`。

## 使用说明

- 默认进入“单件利润”模式，使用推荐 10× 异常价格过滤。
- 打开面板只会读取商品列表；启用异常过滤或总利润模式后，需点击右上角“开始计算”。
- 计算完成后会缓存结果。关闭再打开会直接显示缓存，不会自动重新请求；需要更新时点击“重新计算”。
- “刷新数据”只重新读取商品列表，不会自动启动报价计算。
- 异常过滤不会只隐藏某一个总价字段，而是从买卖报价、在售数量和总利润匹配中一起剔除异常报价。
- 异常过滤是统计规则，不代表报价一定无效；正常报价差异较大时可以切换到 20× 或关闭过滤。
- 点击“总利润”后，扩展会读取各商品的收购和出售报价并计算可执行的最大利润。由于商品较多，第一次计算可能需要约 1 至 2 分钟，具体取决于接口速度。
- “刷新数据”会清空缓存并重新读取。
- 搜索框只按商品名称过滤。
- 最低在售数量留空表示不限；输入数量后，当前表格和统计结果都会按该下限筛选。
- “商品版本”依据商城返回的 vanillaId 判断：有该字段为原版，否则为非原版。
- 点击商品名称即可跳到商城页面中该物品的详情：扩展会在商城的物品列表里定位该物品并打开它，被选中的那一行会短暂高亮，方便确认落点。
  - **面板默认保持打开**，并自动收窄停靠在右侧，商城的详情弹窗会给面板让出空间，两者左右并排互不遮挡，方便一边看详情一边对照排行。
  - 想临时全屏看排行，点面板右上角的 `⤢` 「展开面板」即可回到原来的浮层模式；想彻底关掉这个行为，取消页脚的「跳转后保留面板」勾选（该选项会记住）。
  - 窗口宽度不足 900px 时左右并排没有意义，此时会退回「跳转即关闭面板」。
  - 跳转只使用商城自己的界面，不会改动商城的筛选条件（除非目标物品不在当前列表里，此时会自动在商城搜索框填入物品名并保留，便于你继续查看）。
  - 跳转不会触发或打断报价计算；如果计算正在进行，跳到详情后计算会在后台继续。
  - 只要当前页面能读到商城的物品列表即可跳转（`/`、`/mall` 都可以）；如果页面里完全没有商城物品列表，会在面板里给出提示而不会乱跳。
  - 并排模式下按 `Esc` 只会关掉商城的物品详情，不会连带把利润面板也关掉；详情关掉后再按 `Esc`，面板才关闭。
- 点击“港口黑名单”可选择、搜索或手动添加港口；导出会生成 JSON 文件，导入支持 JSON、TXT 和 CSV。
- 修改港口黑名单后需要手动点击“开始计算”，新的屏蔽条件才会应用到报价和总利润。
- 总利润不是“单件利润 × 在售数量”，而是按买卖报价数量配对后的利润，因此可能出现单件利润很高但总利润较低的商品。

## 文件结构

- `manifest.json`：Chrome 扩展配置。
- `content.js`：页面注入、接口读取、界面、缓存与跳转逻辑。
- `profit-core.js`：利润匹配、排序与港口黑名单解析算法。
- `content.css`：页面内嵌界面样式。
- `tests/profit-core.test.js`：核心算法测试。

## 更新说明

### v1.7.0

新增：

- 点击商品名打开商城详情后，利润排行面板不再自动关闭，而是收窄停靠到右侧，与商城详情左右并排，方便对照查看。
  - 商城的详情是一个铺满视口的模态弹窗，因此面板收窄的同时会让它让出右侧空间，实测两者之间保留 16px 间隙、完全不重叠。
  - 并排时不再用遮罩压暗商城页面，也不再锁定页面滚动，商城的详情可以正常滚动和操作。
  - 面板右上角新增 `⤢` 「展开面板」，可随时回到原来的全屏浮层模式；页脚新增「跳转后保留面板」开关（默认开启）并可记住选择。
  - 窗口宽度不足 900px 时自动退回「跳转即关闭面板」。
  - 并排模式下 `Esc` 只关闭商城的物品详情，不会连带关闭利润面板。

### v1.6.1

修复：

- 从商城根路径 `https://mall.vesego.xyz/` 打开页面时，点击商品名会误报“当前页不是商城首页（/mall），无法跳转到物品详情”而拒绝跳转。
  商城实际是同一个单页应用挂在 `/`、`/mall` 等多个路径上，服务端对任意路径都返回同一份页面，因此跳转判断改为直接检查页面里有没有商城的物品列表，不再依赖 URL 路径。
- 商城物品列表尚未挂载完成时（例如刚刷新页面立刻点击），会先短暂等待最多 2 秒再判定失败，避免误报。

### v1.6.0

新增：

- 点击商品名称可直接在商城页面中打开该物品详情（详见“使用说明”）。
- 参数异常时给出明确提示，不再静默失败：商城接口字段缺失、港口黑名单文件格式不正确、报价条数超过上限被截断、本地缓存写入失败，都会在面板里显示原因。

修复：

- 港口黑名单列表勾选港口后，滚动位置不再跳回顶部。
- 导入格式不正确（例如只有 `format` 字段、或端口数组缺失）的文件时，不会再静默清空当前已选港口，而是报错并保留原选择。
- 商城接口返回结构变化时，不再显示“0 个商品”，而是明确提示接口字段异常。
- 港口黑名单弹窗打开后自动聚焦搜索框，关闭后焦点回到“港口黑名单”按钮。

工程：

- `manifest.json` 增加 `unlimitedStorage` 权限，避免商品缓存增长后触发存储配额上限。
- 新增 `parsePortBlacklistText` 纯函数并补充单元测试。
- 跳转改为轮询定位目标行：商城在搜索时会整表卸载重建，绑定在旧表格节点上的监听会失效。
- 新增 `tools/e2e/` 验证脚本（jsdom 无头测试与真实浏览器注入测试），详见该目录的 `README.md`。
