# 商店利润筛选器

这是一个 Chrome Manifest V3 扩展，支持两个商城：**鸢尾花商城**（`https://mall.vesego.xyz/`）可以筛选利润、过滤异常价格、屏蔽指定港口，还能把计算范围收窄到「当前筛选结果」；**SMCShop**（`https://shop.whalemc.com/`）做玩家商店挂单的单件利润排行，并带价格倍率上限与挂单库存核对，用来滤掉玩家乱标价、以及标了价却没有货造成的虚高利润。两边都是点击商品名直接跳到对应的物品详情。

当前版本：`v1.13.0`

## 快速开始

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `mall-profit-extension` 目录。
5. 打开或刷新商城页面。

详细使用说明见 [`mall-profit-extension/README.md`](mall-profit-extension/README.md)。
