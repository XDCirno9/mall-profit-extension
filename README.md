# SimMC 商城利润筛选器

这是一个 Chrome Manifest V3 扩展，用于在 `https://mall.vesego.xyz/` 商城页面中筛选利润、过滤异常价格和屏蔽指定港口。点击利润列表中的商品名可直接打开商城的物品详情，详情会盖在面板之上，关掉详情后排行原样回来。计算范围可以收窄到「当前筛选结果的最前面 N 条」，不必每次都为全部商品拉一遍报价。

当前版本：`v1.10.0`

## 快速开始

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `mall-profit-extension` 目录。
5. 打开或刷新商城页面。

详细使用说明见 [`mall-profit-extension/README.md`](mall-profit-extension/README.md)。
